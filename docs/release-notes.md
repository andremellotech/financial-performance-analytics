# Publicar a versão 1.0.0

Depois de enviar os arquivos e conferir o workflow de validação:

1. No repositório, abra Releases e escolha criar uma nova Release.
2. Crie a tag **v1.0.0** apontando para a branch main com esta entrega.
3. Use o título **Financial Performance Analytics 1.0.0**.
4. Copie as notas abaixo, anexe excel/FinancialPerformance.xlsx e o ZIP completo desta versão.
5. Confira se a tag, anexos e notas correspondem ao mesmo código. Publique a Release.

## Notas para a Release

Caso fictício de análise financeira com Power BI, Excel, DAX, Power Query e Python.

- Sete páginas: Executiva, Orçado × realizado, Build-up, Motivadores, Mensal, Projeção/EAC e Áreas.
- Cenários editáveis na prévia e no Excel; EAC Base no Power BI.
- Histórico preservado e projeção somente dos meses após o corte.
- Guia de uso e recomendações gerenciais com hipóteses e limitações explícitas.
- Dados reproduzíveis e testes de reconciliação.

Limites: abertura/renderização, atualização M e execução DAX no Power BI Desktop e recálculo nativo no Excel ainda precisam ser conferidos. Não inclui integração SAP, carryover ou estimativas de risco.

Referência: [Releases no GitHub](https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases).
